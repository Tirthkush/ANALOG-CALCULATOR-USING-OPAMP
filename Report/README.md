# Project Reports

This folder contains the documentation and reports related to the **Analog Calculator Using Op-Amp** project.

## Contents
1. Design report (PDF/DOC)
2. Simulation results and analysis
3. Supporting notes, references, and explanations

## Usage
- Open the report files to understand the design methodology, circuit behavior, and performance analysis.
- These documents complement the schematic and symbol files in the `Circuit Files` folder.
